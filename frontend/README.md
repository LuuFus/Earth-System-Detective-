# Earth System Detective: фронтенд

**Українська** | [English](README.en.md)

Проєкт для NASA Space Apps Challenge 2026, челендж **Earth System Trend Detective**.
React + TypeScript + Vite, глобус на Three.js. Дизайн-система описана в
[`../DESIGN.md`](../DESIGN.md).

## Запуск

```bash
npm install
npm run dev        # браузер відкриється сам (порт 5173, або 5174, якщо 5173 зайнятий)
npm run build      # перевірка типів і збірка в dist/
```

Живий сайт GitHub Actions збирає з гілки `main`, а показує GitHub Pages:
https://luufus.github.io/Earth-System-Detective-/ (під час збірки `VITE_BASE`
дорівнює шляху репозиторію, локально сайт працює з `/`).

Потрібен інтернет: відео йде з серверів NASA (images.nasa.gov, eol.jsc.nasa.gov),
знімки Землі з NASA GIBS. Кліматичні дані лежать у самому сайті
(`public/data/gistemp`, 2,4 МБ).

## Що вміє 3D-Земля (`/explore`): «Студія»

Зліва панель інструментів: **Шари, Справи, Аналіз, Глосарій, Поділитися**. Знизу
шкала часу з кнопкою «Відтворити». Справа панель аналізу.

- **Глобус**: обертання, колесо миші або два пальці, до ~95 км над поверхнею.
  Основа: NASA Blue Marble (500 м), а зблизька мозаїка Landsat WELD (30 м,
  знімки 1998-2000 років). Знімки NASA GIBS приходять тайлами з CDN, дедалі
  чіткіші для видимої ділянки. Нова ділянка чи новий рік з'являються цілком,
  коли догрузилися (або за 2,5 с), тож не буває суміші масштабів чи голої
  карти. Шари лежать на тій самій сфері, що й карта, тому зблизька не
  зсуваються. Кадр перемальовується лише тоді, коли щось змінилося.
- **Шари**: 12 змінних NASA. Для кожної є просте визначення:
  - *з числами*: аномалія температури (GISTEMP, 1880–2025), а також температура
    повітря, опади, волога ґрунту й вологість (NASA POWER, MERRA-2, 1981–2025),
    площа озонової діри (NASA Ozone Watch, 1979–2025), а над Україною щомісячні
    NO₂ (OMI, 2005 – березень 2026), рослинність і температура поверхні (MODIS,
    з 2000 року) та кількість пожеж (NASA FIRMS, VIIRS, з 2012 року);
  - *поки лише карта*: нічні вогні (VIIRS) і знімок у справжніх кольорах. У
    знімку смуги без даних між обертами MODIS Terra заповнено знімком іншого
    супутника того ж дня (VIIRS з 2016 року, MODIS Aqua з 2002-го).
  - Для шарів-знімків показується офіційна легенда NASA GIBS.
- **Війна в Україні**: окуповані громади, частково окуповані й громади з
  активними бойовими діями за офіційним переліком Мінрозвитку (наказ № 376).
- **Аналіз**: клацніть місце на глобусі (регіон A), за бажанням додайте регіон B.
  Панель будує часовий ряд і показує:
  - нахил Тейла-Сена з 95% довірчим інтервалом;
  - тест Манна-Кендалла й t-тест;
  - світлофор: «тренд значущий», «тренд є, але незначущий» або «замало даних»;
  - оцінку Вейтерхеда (1998), скільки ще років потрібно до значущості;
  - порівняння A і B: «у N раза швидше» або «протилежні знаки»;
  - плитки: зміна за період, рекордний рік і останній рік проти середнього.

  Нагорі одне речення простою мовою: що змінилося, на скільки і чи це надійно
  («Київ: за 1981-2025 роки стало тепліше приблизно на 2,4 °C»). Терміни
  статистики сховано в «Подробиці для тих, хто знає статистику».

  Графік **по роках** продовжує тренд на 10 років уперед зі смугою 95%, у яку
  має потрапити окремий рік, якщо тренд триватиме. Позначки подій пояснюють
  злами («Пінатубо», «Ель-Ніньйо», «Монреальський протокол», «Вторгнення»).
  Клацніть рік на графіку, і глобус покаже цей рік. Графік **по місяцях**
  показує останні чотири роки, середнє за період і очікуваний наступний рік.

  Розмір регіону: точка, 250, 500 чи 1000 км. Для місячних даних є вибір сезону.
  Графік завантажується в CSV (разом із продовженням тренду) і PNG.
- **Підказки на глобусі**: коли наблизитися до місця, де сталося щось помітне
  (пожежі в Чорнобильській зоні 2020, паління полів, Каховка, Арал, озеро Чад,
  Пінатубо, Амазонія 2019, Канада 2023, арктичний лід), з'являється «!». Картка
  розповідає, що це, і дає посилання на статтю NASA та знімок того дня в NASA
  Worldview. Кожне твердження взято з цих джерел.
- **Шторка «до і після»**: кнопка «Порівняти роки» на шкалі часу ділить глобус
  лінією; ліворуч один рік, праворуч інший. Працює для GISTEMP і всіх
  шарів-знімків, лінію можна тягнути або рухати стрілками.
- **Справи детектива**: 8 готових розслідувань. Камера летить у місце, вмикає
  шар і рахує тренди наживо:
  - Арктика;
  - «дірка потепління» біля Гренландії;
  - Аральське море (шторка 2000 / 2025);
  - Каховське водосховище (шторка 2022 / 2023);
  - озонова діра;
  - Сахель;
  - Україна (клімат);
  - Україна (війна з космосу).
- **Відтворити**: анімація років на глобусі, наприклад 1880 → 2025 для
  GISTEMP. Швидкість 1×, 2× або 4×.
- **Поділитися**: адреса сторінки завжди містить поточний вигляд (шар, роки,
  регіони, справа, камера). Кнопка копіює її.

Статистику звірено зі SciPy: нахил Сена, довірчий інтервал і p-value t-тесту
збігаються до п’ятого знака.

## Оновлення кліматичних даних

```bash
python data-pipeline/build_gistemp.py            # з кореня репозиторію
python data-pipeline/build_gistemp.py --refresh  # скачати найсвіжіший файл GISTEMP
```

Скрипт качає `gistemp1200_GHCNv4_ERSSTv5.nc.gz` (~26 МБ) з NASA GISS у
`data-pipeline/cache/` (не потрапляє в git), усереднює кожну клітинку по
календарних роках (щонайменше 9 місяців з даними) і пише
`public/data/gistemp/annual.bin` та `meta.json`. Потрібен Python з numpy і scipy.

Інші скрипти:

```bash
python data-pipeline/build_ozone.py        # NASA Ozone Watch: площа озонової діри по роках
python data-pipeline/build_occupation.py   # офіційний перелік ТОТ + межі громад з OpenStreetMap
```

`build_occupation.py` бере три DOCX-файли переліку з zakon.rada.gov.ua (наказ
№ 376, поточна редакція), для кожного населеного пункту лишає статус без дати
завершення і зводить їх до громад. Межі громад беруться з OpenStreetMap за
кодами КАТОТТГ (тег `katotth`), © OpenStreetMap contributors, ODbL. У Криму
громад на місцях немає, а Севастополь у переліку стоїть цілим, тому їх
намальовано межами районів: вони йдуть берегом, а не межею територіального моря.
Зараз це 149 окупованих громад поза Кримом, а також Крим і Севастополь, 24 частково окуповані
й 60 громад з активними бойовими діями. Коли вийде нова редакція, передайте нові
посилання й дату:
`--docx URL URL URL --edition ДД.ММ.РРРР`.

Для даних NASA Earthdata потрібен безкоштовний токен Earthdata Login: скопіюйте
`data-pipeline/.env.example` у `data-pipeline/.env` і вставте токен туди (не в
`.env.example`!). Файл `.env` у git не потрапляє.

```bash
python data-pipeline/build_no2.py         # OMI NO₂ над Україною, щомісяця з 2005 року (~35 хв)
python data-pipeline/build_modis.py ndvi  # MODIS рослинність (NDVI), щомісяця з 2000 року
python data-pipeline/build_modis.py lst   # MODIS температура поверхні суші вдень
python data-pipeline/build_fires.py       # NASA FIRMS: пожежі в Україні по місяцях, з 2012 року (токен не потрібен)
```

`build_no2.py` бере щоденні файли OMNO2d v003 через хмарний OPeNDAP NASA і
читає лише прямокутник над Україною (44-53° пн. ш., 22-41° сх. д.), близько
40 КБ на день замість 11 МБ. Для кожної клітинки 0,25° усереднює дні місяця
(щонайменше 3) і пише `public/data/no2/ukraine.bin` та `ukraine.json`. Прогрес
кешується по місяцях, тож перерваний запуск продовжиться з того ж місця. Місяці,
за які в архіві NASA немає файлів (OMI після березня 2026), лишаються порожніми.

`build_modis.py` так само читає з MOD13C2 і MOD11C3 лише прямокутник над Україною
і усереднює пікселі 0,05° у клітинки 0,25°. `build_fires.py` бере публічний
річний архів NASA FIRMS для України (VIIRS 375 м) і рахує виявлення по місяцях;
промислові джерела (тип 2), шельф (тип 3) і виявлення низької впевненості не
враховано.

Рік у цих рядах — середнє місячних відхилень від норми кожного місяця плюс
середня норма, коли є щонайменше 9 місяців: так пропущений зимовий місяць (хмари,
сніг) не тягне рік угору чи вниз.

## Як змінювати вміст

- **Тексти сайту**: правте обидві мови, `uk` і `en`, у `src/i18n/strings.ts`.
- **Фонове відео**: `filmClips` у `src/data/media.ts`. `start` і `end` — секунди
  у вихідному відео, `rate` сповільнює короткий таймлапс. Уникайте фрагментів із
  вшитими титрами.
- **Якість відео**: 1080p на великих екранах зі швидким інтернетом, 720p в
  інших випадках, 640px на телефонах і повільному або економному з'єднанні.

Логотипи NASA не використовуються; у підписі сказано, що це не офіційний сайт NASA.
